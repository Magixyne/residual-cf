# MovieLens 数据集

本目录随项目提供 ml-latest-small 历史快照：

- ratings.csv：100,004 条带时间戳评分。
- movies.csv：9,125 条影片目录记录，其中 9,066 部有评分。
- links.csv、tags.csv：MovieLens 配套映射与标签。
- demo_data.json、evaluation_results.json：项目生成的推荐缓存和评估输出。

来源：GroupLens Research，https://grouplens.org/datasets/movielens/ 。重新分发时请遵循其数据集使用条款。
